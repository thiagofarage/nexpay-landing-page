# Marca Nexpay — arquivos para Figma

- nexpay-symbol-black.svg: matriz preta para fundos claros.
- nexpay-symbol-white.svg: inversão branca para fundos escuros.
- nexpay-logo-black.svg e nexpay-logo-white.svg: símbolo com assinatura tipográfica.

O símbolo foi reconstruído geometricamente a partir do print fornecido, não do arquivo vetorial original. É uma aproximação fiel à estrutura de três peças observada, não uma extração do original.

A assinatura usa Space Grotesk Bold como aproximação tipográfica; o lettering do print não foi fornecido como vetor. Instale Space Grotesk para editar o texto no Figma. O aplicativo carrega a mesma fonte localmente por @fontsource/space-grotesk. Se houver uma versão com texto convertido em curvas, ela será identificada como outlined.

Não adicione uma caixa ou letra N ao símbolo. Mantenha suas três peças, as proporções 60:52 e espaço livre ao redor de pelo menos metade da altura. Use a versão Black em fundos claros e sua inversão branca em fundos escuros.

## Versões prontas em curvas

Os arquivos nexpay-logo-black.svg e nexpay-logo-white.svg têm o nome convertido em caminhos: podem ser importados no Figma sem instalar fontes. As variantes -editable.svg mantêm texto para edição e exigem Space Grotesk. A assinatura tipográfica é uma aproximação, não o lettering original do print.
